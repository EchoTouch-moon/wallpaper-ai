# P1.2 koffi 重写：直接 FFI 调用 user32.dll

- **状态**: Mac 验证通过；Windows 复验待确认
- **分支**: `desktop/dynamic-layer-v1`
- **日期**: 2026-07-04
- **触发原因**: P1.1 的 Rust patch 路线失败（patch 不生效、桌面被遮挡）

## 为什么放弃 `electron-as-wallpaper`

调研三个成熟开源壁纸应用（C 的 weebp、C# 的 Lively Wallpaper、C++ 的 SpoutWallpaper），确认它们调用 user32.dll 的序列**完全一致**。对比发现 `electron-as-wallpaper`（Rust 封装）漏掉了三个关键步骤：

| 步骤 | Lively/weebp 正确做法 | electron-as-wallpaper | 后果 |
|---|---|---|---|
| 发现 WorkerW | EnumWindows 找含 SHELLDLL_DefView 的窗口，取**下一个兄弟** WorkerW | 找不到就回退 Progman | reparent 进错父窗口 |
| 预定位 + 坐标变换 | SetWindowPos(HWND_BOTTOM) → MapWindowPoints → SetParent → SetWindowPos | 只调 SetParent | 多屏错位、Z 序乱 |
| SWP_NOACTIVATE flag | flags 含 `0x0010`（绝不激活壁纸窗口） | 缺失 | Win11 把激活的 reparent 子窗口当死锁、销毁 |

继续 patch 它的 Rust 源码是死路——漏的不只是 flag，是整个发现+定位序列。

## 改用 koffi（纯 JS FFI）

- 删除 `electron-as-wallpaper` 依赖 + pnpm patch
- 删除 `patches/` 目录
- 新增 `koffi`（纯 JS，无原生编译）→ **Windows 不再需要 Rust 工具链 / VS Build Tools**
- 实现 `src/main/win32/user32.ts`：直接调 user32.dll 的 FindWindowW / SendMessageTimeoutW / EnumWindows / FindWindowExW / SetParent / SetWindowPos

## 实现的完整序列（来自 Lively/weebp 验证）

```
1. FindWindowW("Progman") → progman
2. SendMessageTimeoutW(progman, 0x052C, 0, 0, SMTO_NORMAL, 1000)  // 生成 WorkerW
3. EnumWindows: 找含 SHELLDLL_DefView 的顶层，取其下一个兄弟 WorkerW ← 正确的壁纸 WorkerW
4. SetWindowPos(hwnd, HWND_BOTTOM, x, y, w, h, SWP_NOACTIVATE)    // 预定位，绝不激活
5. SetParent(hwnd, workerW)                                       // reparent
6. SetWindowPos(hwnd, HWND_BOTTOM, x, y, w, h, SWP_NOACTIVATE)    // 再定位
```

## 关键洞察：点击穿透是结构性的，不需要 setIgnoreMouseEvents

Lively 根本不用 `WS_EX_TRANSPARENT` 或 `setIgnoreMouseEvents`。窗口树正确时，图标在 `SHELLDLL_DefView`（WorkerW 的**兄弟**，在它**上面**），图标点击天然落到图标上。壁纸窗口只是空桌面区域的承载者。所以我们移除了 `setIgnoreMouseEvents` 调用和 `transparent:true`。

## 如有问题

| 现象 | 排查 |
|---|---|
| `[win32] Progman not found` | Explorer 没运行；重启 explorer.exe |
| `[win32] wallpaper WorkerW not found` | 发 0x052C 后没生成 WorkerW；检查 Progman 句柄是否有效 |
| `[win32] SetParent failed` | 窗口句柄无效；确认 show() 在 embed 之前调用 |
| 窗口在前台而非桌面层 | SWP_NOACTIVATE 没生效；确认 koffi 的 flag 值传对（0x0010） |
| Win11 24H2 切主题后消失 | WorkerW 被销毁（已知）；P2 加 re-embed 监听 |
