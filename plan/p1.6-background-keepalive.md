## 剩余 bug：后台节流导致变白

**症状**：三联画能稳定显示，但用户切到其他窗口一会儿后，壁纸层变成纯白色。

**根因**（报告诊断准确）：
- 壁纸窗口 `focusable:false` + `SWP_NOACTIVATE` → 永远不是激活窗口
- Chromium 对后台窗口做渲染节流
- 软件渲染模式下，节流会释放 paint target → 内容丢失变白

**我的失误**：P1.5 删 `setBounds` 时，把 `setBackgroundThrottling(false)` 也一起删了。这个设置正是防后台节流的，删错了。

## 本次修复

| 修复 | 位置 | 作用 |
|---|---|---|
| `webPreferences.backgroundThrottling: false` | 窗口创建时 | 从根上禁用后台节流（比运行时 `setBackgroundThrottling` 更可靠，文档推荐的位置） |
| 30s `invalidate()` 心跳 | embed 之后 | 保活：强制合成器周期性重绘，防止某些 Windows build 上节流仍生效 |
| 移除诊断代码 | renderer | 删品红背景、H1 大字、boot badge（已完成历史使命），恢复正常 `#0b1120` 背景 |
