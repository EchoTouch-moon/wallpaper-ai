# P2.4 — 每 slot 独立定时轮换

- **状态**: ✅ 实机验证通过（2026-09-05）
- **分支**: `desktop/dynamic-layer-v1`
- **前置**: P2.2 控制平面（plan/p2.2-swap-control-plane.md）。本切片把"手动触发换图"扩展为"按配置自动轮换"，对应总计划 P4 的核心验收（hero 每 10min、support 每 30min 各自轮换）。

## 1. 设计

复用 P2.1 事件循环的 `ControlFlow::WaitUntil` 绝对截止时间模式与 P2.2 的换图链路，宿主内不加任何线程：

```
--rotate center=600 --rotate left=1800   ← CLI 静态配置（SQLite 配置面留给编辑器切片）
        │ 启动时解析（fail fast：slot 名白名单校验、间隔 ≥5s、必须配 --assets）
        ▼
HostState.rotations: Vec<RotateRule{ slot, interval, next_at }>
        │ next_deadline() 取 min(next_at) 参与 WaitUntil 唤醒计算
        ▼
schedule() Running 分支 → run_due_rotations()
        │ 仅 Running 触发；错过期间（恢复/重建）的 tick 在恢复 Running 后补发一次
        │ AssetPool.rotate(slot)（跨 slot 防撞图，P2.2 语义）
        ▼
push_swaps_to_renderer()（与控制服务器 SwapApplied 共用的 evaluate_script 推送）
```

关键点：

| 项 | 决策 | 理由 |
|---|---|---|
| 配置面 | `--rotate SLOT=SECONDS`（可重复） | 最小可用；rotation_rules 的持久化/编辑随编辑器窗口切片做 |
| 触发线程 | 无新线程——rotate deadline 并入 `next_deadline()`，事件循环自然唤醒 | 遵守 P2.0"零空闲 CPU"裁决；与 guardian/status 同一模式 |
| 触发门禁 | 仅 `Running` | 恢复/重建期间无活跃 webview；`next_at` 保持绝对时间，恢复后首个 tick 补发一次并重新对齐节奏 |
| 推送路径 | 与手动 swap 完全共用（`push_swaps_to_renderer`） | 单一推送实现，行为一致，便于审查 |
| 非法配置 | 启动即报错退出（未知 slot、间隔 <5s、无 --assets） | 配置错误不该等到运行期才暴露 |

## 2. 实机验证（Win11 22H2，2560×1600 @150%，reparent-click-through 模式）

启动：`wallpaper-host --renderer ... --assets .local/test-assets --mode reparent-click-through --rotate center=8 --rotate left=15`

| 项 | 结果 |
|---|---|
| 自动轮换日志：center 每 8s（img-05→06→07）、left 每 15s（img-02→04） | ✅ 无任何人工触发 |
| 无规则的 right 全程不动（img-03） | ✅ |
| 跨 slot 防撞图在自动轮换下同样生效 | ✅ |
| 每次轮换推送渲染层（`[swap] pushed 1 swap(s)`） | ✅ |
| PrintWindow 前后抓图（间隔 9s，无触发）：仅 center 变化（绿 img-05→粉 img-07），left/right 不动 | ✅ `.local/rot-before.png` / `rot-after.png` |
| 非法配置 fail fast（未知 slot / 间隔过小 / 缺 --assets） | ✅（启动报错路径） |
| 单测回归 8/8；`cargo build` 无警告 | ✅ |

## 3. 边界与后续

- 轮换计划目前是 CLI 静态配置；`rotation_rules` 的持久化与编辑器 UI（总计划 P3 的 editor window）后续接入。
- 多显示器（P3）受本机单屏限制，无法实机验证，保持未动。
- 与控制平面互不冲突：手动 `/swap` 与定时轮换共用同一 AssetPool 游标，手动换过的图不会立刻被轮换换回（游标推进）。
