### B. 渲染问题诊断 + 修复

**症状**：窗口外壳可见（"wallpaper AI 外框"），中间显示用户原壁纸，三联画未渲染。

**最可能根因**：Electron 的 GPU 合成器在 Win32 `SetParent` reparent 到 WorkerW 后**停止呈现**——swap chain 在窗口被外部 reparent 时不会自动恢复。

**修复**（`main/index.ts`）：
1. **调整加载顺序**：先 `loadURL`（让合成器在普通顶层窗口时启动），再 embed。比"先 embed 后 load"更可靠。
2. **embed 后强制重绘**：`setBounds` 微调尺寸（触发 swap chain 重建）+ `webContents.invalidate()`（强制合成器重绘）+ 关闭后台节流。

### C. 诊断工具（区分"窗口空"vs"React 没挂载"）

- `index.html` 加了**纯品红色不透明诊断背景** + "HTML loaded / React mounted" 启动徽章。
- 看 Windows 桌面，能立刻判断故障层：
  - **看到品红色** → 渲染器在画，问题是 React/CSS
  - **看到用户原壁纸**（透过来） → 渲染器没在画，GPU 合成器问题
  - **徽章一直在** → React 没挂载（脚本错误）
  - **徽章消失但无三联画** → WallpaperStage 内部问题
- `WallpaperStage` 容器背景临时设为透明，让品红从 slot 间隙透出。**确认渲染稳定后改回 `#0b1120`。**
