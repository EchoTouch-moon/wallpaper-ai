### B. Rust 原生模块补丁（pnpm patch，install 自动应用）

**`electron-as-wallpaper@2.0.3` 的 `src/attach.rs`**（错误 6 核心层）：

原 `attach()` 调 `SetParent(hwnd, worker_w)` 后窗口在 WorkerW 子窗口 Z 序顶端，**遮挡桌面图标**（SHELLDLL_DefView），Win32 认为窗口卡死自动销毁。

**补丁内容**（`patches/electron-as-wallpaper@2.0.3.patch`）：在 `SetParent` 后追加 `SetWindowPos(hwnd, HWND_BOTTOM, SWP_NOMOVE|SWP_NOSIZE)`，把窗口推到 WorkerW Z 序底部，让桌面图标保持可见可点击。

**生效方式**：`apps/desktop/package.json` 的 `pnpm.patchedDependencies`，每次 `pnpm install` 自动应用，不再手动改 `node_modules`。

### C. 环境问题（不写进依赖，写进文档）

**错误 1（Electron 二进制 ICU 数据缺失）+ 错误 2（path.txt CRLF）**：根因是 Electron 二进制下载损坏 + PowerShell 写换行符。**不**用往 `package.json` 加 `@electron-internal/extract-zip`（那是内部包）。正确处理见下方"Windows 环境一键准备"。

## Windows 环境一键准备（应对错误 1/2）

```powershell
# 1. 装 pnpm + Rust + VS Build Tools（见 plan/p1-desktop-shell-poc.md）

# 2. 清空损坏的 Electron 缓存（解决错误 1 的 0 字节 zip）
Remove-Item -Recurse -Force "$env:LOCALAPPDATA\electron\Cache" -ErrorAction SilentlyContinue
Remove-Item -Recurse -Force "$env:LOCALAPPDATA\electron-builder\Cache" -ErrorAction SilentlyContinue

# 3. 用国内镜像下载完整二进制（解决错误 1）
$env:ELECTRON_MIRROR = "https://npmmirror.com/mirrors/electron/"
$env:ELECTRON_BUILDER_BINARIES_MIRROR = "https://npmmirror.com/mirrors/electron-builder-binaries/"

# 4. 安装（patch 自动应用，electron-as-wallpaper 会编译）
pnpm install

# 5. 验证 Electron 二进制完整（应有 icudtl.dat 等，不是只有 default_app.asar）
ls apps/desktop/node_modules/electron/dist/
# 若仍损坏，手动重下：
# node -e "require('@electron/get').downloadArtifact({version:'43.0.0',platform:'win32',arch:'x64'})"
```
