# Windows 复验问题报告

## 一、pnpm patch 持久化失败（阻塞）

| 项目 | 详情 |
|---|---|
| **现象** | `pnpm install` 后，`electron-as-wallpaper` 的 `src/attach.rs` 中**无补丁代码** |
| **影响** | SetWindowPos Z 序修正未生效，wallpaper 窗口 Z 序行为不可控 |
| **根因** | `pnpm-lock.yaml` 中无 patch 字段记录，install 跳过了 patch 应用 |
| **复现** | `pnpm install` → 检查 `node_modules/.pnpm/electron-as-wallpaper@2.0.3/.../src/attach.rs` 第 96 行后无新增代码 |

---

## 二、桌面被完全遮挡（阻塞）

| 项目 | 详情 |
|---|---|
| **现象** | 应用启动后桌面被完全遮挡，无法进行任何操作 |
| **影响** | P1 Windows 验证未通过，无法继续 P2 |
| **当前状态** | `main/index.ts` 无 `transparent: true`；`win32.ts` attach 无 `transparent: true`；`global.css` 为 `#0b1120` 不透明背景 |
| **根因分析** | 三层不透明叠加：Electron 窗口默认不透明 + CSS 不透明背景 + WorkerW 内 Z 序不确定 |

---

## 三、补丁编译类型错误（已发现模式）

| 项目 | 详情 |
|---|---|
| **现象** | `FindWindowExA` / `GetWindow` 返回 `Result<HWND, Error>`，原补丁直接传递导致编译失败 |
| **影响** | 补丁无法编译通过，需手动 `.unwrap_or(HWND::default())` |
| **模式** | `windows` crate v0.58 返回 `Result`，补丁中需解包 |

---

## 四、Patch 文件格式疑似不匹配 pnpm 版本

| 项目 | 详情 |
|---|---|
| **现象** | 补丁文件存在但 pnpm install 未应用 |
| **可能原因** | pnpm 11 的 patch 格式/字段与 lockfile 记录机制有变化，需确认 `patchedDependencies` 在 lockfile 中的正确存储方式 |
| **待确认** | pnpm 11 是否仍需额外步骤（如 `pnpm patch` 命令）来注册 patch |

---

## 五、Z 序策略不确定

| 项目 | 详情 |
|---|---|
| **候选策略 A** | `SetWindowPos(hwnd, shell_view, ...)` — wallpaper 紧贴图标下方 |
| **候选策略 B** | `SetWindowPos(hwnd, below, ...)` — wallpaper 在图标与背景之间 |
| **风险** | 不同系统/桌面配置下，`GW_HWNDNEXT` 取到的窗口可能不同，行为不一致 |
| **待验证** | 哪种策略在真实桌面环境下图标可点击且 wallpaper 可见 |

## 优先级排序

1. 修复 pnpm patch 持久化机制（否则每次 install 都丢失 Rust 层修正）
2. 恢复 `transparent: true` + CSS 透明背景（否则桌面始终被遮挡）
3. 确定 Z 序策略并验证图标可点击
